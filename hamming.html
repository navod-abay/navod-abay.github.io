Hypercube Graph Qn

The vertices of Qn are all 2n binary strings of length n. Two vertices are joined by an edge iff they differ in exactly one bit — i.e. their Hamming distance is 1. Every vertex has degree n, so Qn has n·2n−1 edges.

Linear Codes as Subspaces

A binary linear code is a linear subspace C ⊆ GF(2)n: a set of codewords closed under XOR. A code of dimension k has |C| = 2k codewords, generated by XOR-combining any basis of k independent codewords (the rows of a generator matrix).

Code Parameters [n, k, d]

n is the code length, k is its dimension, and d is the minimum distance — the smallest Hamming distance between any two distinct codewords. For a linear code, d equals the minimum Hamming weight (number of 1s) among its nonzero codewords. A larger d means the code can detect/correct more errors.
